Development Roadmap: PertVI (V1.0)Project: Conditional Perturbation Variational Inference (PertVI)Objective: To develop, validate, and publish a specialized deep generative model for disentangling state-dependent transcriptomic responses to perturbations from intrinsic cellular biology.Phase 1: Core Architecture Freeze (Current)Goal: Finalize the mathematical engine, eliminate latent space leakage, and lock the PyTorch computational graph.1.1 Implement Adversarial Disentanglement (The "Blindfold"):Task: Integrate a Gradient Reversal Layer (GRL) and an adversarial classifier to the u_state encoder.Purpose: Force u_state to represent the pure, pre-treatment basal biology by explicitly penalizing it for retaining perturbation-specific variance. This ensures the transition MLP ($z_{shift}$) bears the full burden of learning the mechanism of action.1.2 Expose Internal APIs:Task: Update the get_latent_representation method to return a comprehensive dictionary containing u_cycle, u_state, v_ood, z_shift, z_base, and z_final.Purpose: Provide seamless integration with scanpy allowing users to directly access and plot intermediate mathematical states.1.3 Codebase Freeze:Task: Stop active development on _components.py and _module.py loss functions to prevent scope creep.Phase 2: Downstream Analysis Toolkit (Biological Utility)Goal: Build the user-facing Python functions that translate the mathematical latent spaces into actionable biological insights. Note: These are built entirely outside the core PyTorch model.2.1 Counterfactual Drug Response Generator:Task: Develop a function that accepts an unperturbed cell profile, maps it to u_state, applies a user-specified sample_key (perturbation), and decodes the result.Output: "What would this specific Naive T cell look like if treated with Compound X?"2.2 Density Difference Mapping (Heterogeneity Tracker):Task: Build a visualization wrapper that maps z_base (expected response) against z_final (actual response).Output: Automatically highlights clusters of cells exhibiting out-of-distribution behavior (e.g., drug resistance, extreme stress) captured by v_ood.2.3 Mechanism of Action ($z_{shift}$) Clustering:Task: Isolate the pure $z_{shift}$ vectors across multiple perturbations to cluster drugs by their state-dependent effects, independent of the cell types they were applied to.Phase 3: Benchmarking & Validation (Reviewer Defense)Goal: Rigorously test the frozen model to generate the quantitative figures required for a high-impact methodology publication.3.1 Hyperparameter Optimization:Task: Systematically sweep network depths (e.g., 2 vs. 3 layers), widths (128 vs. 256 neurons), and penalty scheduling ($\lambda_{cov}$, $\lambda_{ood}$) to establish the optimal default configuration.3.2 Quantitative Benchmarking:Task: Run PertVI head-to-head against established ecosystem tools (scGen, Compositional Perturbation Autoencoder [CPA], and standard scVI).Metrics: Compare $R^2$ values of counterfactual predictions and calculate $k$-NN purity scores to objectively prove superior disentanglement of conditional tasks.Phase 4: Future Directions (V2.0 Backlog)Goal: High-value theoretical expansions reserved for follow-up studies or major version updates.4.1 Combinatorial & Multi-Level Perturbations:Concept: Expand the $z_{shift}$ transition module to handle multi-input gating (e.g., conditional DOX-induced states + subsequent gRNA screens like the MYC paradigm) to model epistatic and synergistic interactions.4.2 Specialized Topological Priors:Concept: Replace the standard Gaussian $\mathcal{N}(0, I)$ prior on specific encoders (e.g., using a von Mises-Fisher distribution for u_cycle to natively enforce circular cell-cycle topology).
